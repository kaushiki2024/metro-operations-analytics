# Metro Operations & Passenger Demand Analytics

## Project Overview

This project analyzes metro passenger ridership data to understand passenger demand patterns and identify operational insights.

## Objectives

* Analyze passenger demand across metro stations.
* Identify peak passenger hours.
* Identify high-ridership stations.
* Compare passenger demand across different days.
* Analyze weekday vs weekend patterns.
* Generate insights that can support metro operational planning.

## Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* SQL
* Power BI
